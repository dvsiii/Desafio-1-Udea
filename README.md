# SWEET CRUSH - DESAFÍO 1

## Requisitos
* Qt Creator
* Compilador C++ (Soporte C++17)

## Estructura del Proyecto
* **main.cpp**: Contiene el menú principal y la estructura base para correr el programa.
* **Funciones.cpp**: Implementación de toda la lógica, manejo de memoria y operaciones de bits.
* **Llamado.h**: Cabecera con la declaración de las funciones.
